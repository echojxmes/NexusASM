# Nexus

**A lightweight x86 assembly bootloader.**

Nexus is a low-level programming project focused on exploring x86 assembly, BIOS operations, and the fundamentals of operating system development.

## Overview

Nexus aims to build a minimal bootloader from the ground up, starting with basic screen output and gradually expanding into more advanced boot-time functionality.

## Features

* 16-bit x86 real-mode assembly
* BIOS-based boot process
* Text output during startup
* Custom boot sector
* Designed for testing in an emulated environment

## Tech Stack

* **Assembly:** x86 (16-bit)
* **Assembler:** NASM
* **Emulator:** QEMU
* **Platform:** Legacy BIOS

## Project Status

Currently in early development.

## Goals

* [ ] Create a functional boot sector
* [ ] Print custom messages to the screen
* [ ] Implement basic keyboard input
* [ ] Explore disk operations
* [ ] Expand towards a minimal operating system

## Disclaimer

Nexus is an educational project intended for learning low-level programming and operating system fundamentals. It is not intended to replace an existing bootloader or operating system.
